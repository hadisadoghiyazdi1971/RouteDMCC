# Data Provenance

The reported experiments are simulation-based and do not depend on an external benchmark dataset.

For each run, regressors, nominal measurement noise, impulsive contamination, network topology, and the unknown target parameter are generated by the experiment program from pseudorandom seeds and configuration values. The public repository should therefore be described as providing **experiment code, configurations, and reference outputs**, rather than as hosting a third-party dataset.

## Included data-like artifacts

- configuration snapshots extracted from the frozen result JSON;
- aggregate metric summaries;
- averaged learning curves and their stored standard deviations;
- parameter-sweep summaries;
- reference PNG figures.

## Not claimed

The current result archive is not described as raw sensor data or an independently collected dataset. Files transcribed from the manuscript are kept under `results/paper_reported/` and clearly separated from machine-generated reference JSON.
